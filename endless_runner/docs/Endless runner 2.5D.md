# Laboratorio Orientado a Aplicaciones Móviles
## Trabajo 2

### Resumen del trabajo

1. Desarrollar una app utilizando Flutter framework principal
2. Defender el trabajo individualmente
3. La app se puede presentar en un emulador o bien generando un apk

**ACLARACIÓN:** se puede realizar en grupo pero la defensa es individual.

5. **Fecha de entrega 08/10/2026, se puede negociar**

### Requerimientos

REALIZAR UNA APP GAME, intentar que sea un juego viral que:

- Se valorará la UI/UX, aplicando técnicas vistas en teórico
- Sea Offline, es decir debe funcionar en modo avión sin problemas (si es plan A)
- La autentificación del usuario es simulada, no se debe hacer, se supone que ya entra logueado
- El juego puede ser de cualquier tipo, queda a la creatividad de la persona, puede copiarse un formato ya conocido
- Debe contar con un header donde se pueda ver, nombre de usuario, score y tipo de cuenta (**basic/pro**), mas los diamantes comprados
- Debe tener el concepto de diamantes, se usan dentro del juego (simulado)
- Debe Simular Monetización para comprar esos diamantes
- El juego debe tener botonera de **INICIO, PAUSA, REINICIAR PARTIDA, NUEVA PARTIDA, ETC**, básicamente que lo puedas controlar, estos botones deben ser controlados fuera del juego
- Debe contar con una **PUBLICIDAD**, que puede ser de tipo modal (ventana), un video que se pase cada vez que se reinicia la partida, o temporal, queda a creatividad del desarrollador
- Debe tener modo claro y oscuro, el juego puede ser siempre igual
- **Debe ser atractivo visualmente ya que está pensado para niños**

### Tecnología de desarrollo

**PLAN A**

APP HÍBRIDA EN FLUTTER

Motor de juego: Flame, Unity, Godot, Unreal Engine, Rive

**PLAN B**

WEB APP CON KOTLIN

Motor de juego: javascript+canvas, TypeScript+Phaser, React + Phaser, Three.js, Babylon.js
